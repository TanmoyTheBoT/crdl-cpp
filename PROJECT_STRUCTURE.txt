# Key Design Patterns Used:

1. **PIMPL (Pointer to Implementation)**
   - HttpClient, Downloader, WidevineCDM
   - Hides implementation details
   - Reduces compile times

2. **RAII (Resource Acquisition Is Initialization)**
   - All resources managed by constructors/destructors
   - No manual cleanup needed
   - Thread-safe by design

3. **Result<T> for Error Handling**
   - Type-safe error propagation
   - No exceptions in hot paths
   - Clear error codes

4. **Dependency Injection**
   - Config passed to constructors
   - Easy to test and mock

5. **Separation of Concerns**
   - API layer (auth, requests)
   - DRM layer (decryption)
   - Media layer (download, mux)
   - Utils layer (HTTP, logging)

# Improvements Over Python Version:

✅ Thread-safe stream token management
